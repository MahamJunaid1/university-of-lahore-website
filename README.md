# University of Lahore Website

A responsive university website built with **HTML and CSS** by **Maham Junaid**.

## Open the website

Open `index.html` in a browser. No installation, build tools or JavaScript are required. Keep the files in the same folder.

## Included sections

- Header, navigation and footer
- About the university
- Academic areas
- Admissions guide and official portal link
- Campus life
- Student details practice form
- Frequently asked questions
- Official contact information

## HTML and CSS concepts

The project uses `header`, `nav`, `main`, `section`, `aside`, `footer`, `figure`, `figcaption`, `details`, `summary`, `mark`, `abbr`, `time`, `blockquote`, `address`, `progress` and `meter`.

CSS includes transitions, `rotate()`, `scale()`, `translateX()`, `translateY()`, linear gradients, radial gradients, box shadows, border radius and opacity. Rotation appears when hovering over the campus symbol, navigation shortcuts and programme arrows. Layouts adapt to mobile screens, and reduced-motion preferences are respected.

## Form behaviour

The form uses native HTML validation. Selecting **Preview next steps** validates required fields and opens an on-page message using the CSS `:target` selector. Fields deliberately have no `name` attributes, so their values are not included in the GET request. There is no server, database, email delivery or application submission. Use sample details only. The progress and meter values are labelled examples, not live tracking.

## Repository housekeeping

The `.gitignore` file excludes local environment files and private keys, editor preferences, operating system files, temporary files, logs, backups, optional dependency folders, generated build output and archives. These are patterns for files that may be created later; this static project does not need dependencies or a build step. HTML, CSS, the two photographs, this README and `.gitignore` are the project source files to upload.

Ignoring a file does not delete it, hide an already tracked file, or remove it from earlier commits. Review files before committing. GitHub's browser upload can still upload files manually selected by the user, so select only the intended project files.
